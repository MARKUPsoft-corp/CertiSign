# À propos de CertiSign

## Présentation du projet

CertiSign est une solution complète de signature électronique conçue pour répondre aux besoins des entreprises et des particuliers. Le projet a été développé avec une attention particulière à la sécurité, la conformité légale et l'expérience utilisateur.

## Histoire et vision

CertiSign a débuté comme un projet interne visant à simplifier les processus de signature électronique tout en garantissant le plus haut niveau de sécurité. Avec l'augmentation des besoins en solutions numériques fiables, notamment suite à la pandémie de COVID-19, le projet s'est transformé en une plateforme complète et autonome.

Notre vision est de démocratiser l'accès à la signature électronique légalement contraignante, permettant ainsi aux organisations de toutes tailles de numériser leurs processus documentaires en toute confiance.

## Technologies utilisées

CertiSign repose sur un ensemble de technologies modernes et éprouvées :

### Frontend
- Vue.js avec Nuxt.js pour une interface réactive
- Bootstrap pour un design responsive
- Axios pour les communications API

### Backend
- Django et Django REST Framework pour l'API principale
- FastAPI pour les microservices de signature
- PostgreSQL pour le stockage persistant
- Redis pour le cache et la gestion des sessions
- Celery pour les tâches asynchrones

### Sécurité
- JWT pour l'authentification
- HSM (Hardware Security Module) pour la protection des clés
- Chiffrement de bout en bout
- Conformité aux normes OWASP

## Conformité légale

CertiSign est conçu pour répondre aux exigences légales des différentes régions :

- **Europe** : Conforme au règlement eIDAS (UE) N°910/2014
- **États-Unis** : Conforme à l'Electronic Signatures in Global and National Commerce Act (ESIGN)
- **International** : Conforme à la loi type de la CNUDCI sur les signatures électroniques

## Caractéristiques clés

- **Multi-plateforme** : Fonctionne sur tous les appareils (desktop, mobile, tablette)
- **Multi-format** : Supporte les documents PDF, XML, et autres formats
- **Flexibilité** : S'adapte aux flux de travail existants
- **Sécurité renforcée** : Chiffrement de bout en bout, authentification forte
- **Traçabilité** : Journal d'audit complet pour toutes les actions
- **Intégration** : API complète pour s'intégrer avec d'autres systèmes
